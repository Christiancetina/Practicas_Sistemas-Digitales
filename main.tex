\begin{abstract}
This document details the methodology and performance analysis of implementing two combinational logic circuits using the VHDL hardware description language. Utilizing the Vivado 2026.1 platform and the architecture of the AMD Zynq UltraScale+ MPSoC (XCZU3EG) FPGA, logic functions were synthesized, evaluating their translation from mathematical abstraction and algorithmic schematic (RTL) to their technological mapping in look-up tables (LUTs). The physical area consumption was determined, and the system speed was characterized by measuring the asynchronous propagation delay, demonstrating the majority impact of physical routing interconnections in high-density arrays.
\end{abstract}

\begin{IEEEkeywords}
FPGA, VHDL, Vivado, Zynq UltraScale+, LUT, RTL.
\end{IEEEkeywords}

\section{Introduction}
Boolean algebra provides the necessary axiomatic framework for digital system design. In the current paradigm of field-programmable gate arrays (FPGAs), any mathematical expression is translated into a hardware model through description languages such as VHDL. 

Diverging from legacy architectures, this practice is executed on an advanced hybrid AUP-ZU3 development board featuring the AMD Zynq UltraScale+ MPSoC device. The main purpose is to implement two independent combinational architectures, contrasting the behavior of the idealized logic circuit with the instantiation of real physical resources imposed by the compiler and the silicon routing matrix.

\section{Methodology}
The design consisted of the integration of two independent logic systems to structure the comparative analysis. 

The first circuit evaluates an asynchronous combinational function of four input variables ($A, B, C, D$) and one logic output ($F$), defined by the mathematical expression:
\begin{equation}
F = \overline{(AB+\overline{C}D)} + A\overline{B}C\overline{D} + A\overline{B}(C+D)
\end{equation}

\subsection{VHDL Coding}
The logic functions were implemented in the Vivado 2026.1 development environment. For the first part, a Dataflow approach was used, declaring intermediate signals to illustrate the gate hierarchy:

{\footnotesize
\begin{verbatim}
entity P1E1 is
  Port (a,b,c,d: in std_logic;
        f1: out std_logic );
end P1E1;

architecture P1E1_arch of P1E1 is
  signal E,F,G,H,I,J,K,L,M:std_logic;
begin
  E <= a and b;
  F <= (not c) and d;
  G <= a and (not b);
  H <= c and (not d);
  I <= c or d;
  J <= G and H;
  K <= not(E or F);
  L <= G and I;
  M <= J or L;
  f1 <= M or K; 
end P1E1_arch;
\end{verbatim}
}

For the XNOR circuit (Part II), a direct concurrent structural architecture was chosen, synthesizing the behavior in a single line of code:

{\footnotesize
\begin{verbatim}
entity Actividad2 is
  Port ( i0 : in std_logic;
         i1 : in std_logic;
         eq : out std_logic);
end Actividad2;

architecture Act_arch of Actividad2 is
begin
  eq <= (not i0 and not i1) or (i0 and i1);
end Act_arch;
\end{verbatim}
}

\subsection{Physical Implementation}
The spatial implementation was verified using the \textit{Device View} tool after routing execution. The routing meshes successfully converged towards the previously assigned \texttt{LVCMOS12} pins in the X1Y0 clock region matrix, demonstrating the fidelity of the XDC file. The visual verification of the system was recorded and documented in the supplementary evidence.

\section{Performance Analysis}
To establish a reference analysis, post-logic synthesis, the systems generated within the FPGA and their performance impact were evaluated. 

Upon examining the \textit{View RTL Schematic}, the compiler exhibited the network of multiple interconnected primitive logic gates. However, in the \textit{View RTL Technology} (Post-Synthesis), the synthesizer mathematically compressed these topologies, mapping each circuit into high-speed static memory blocks (LUTs) coupled with physical I/O buffers (\texttt{IBUF} and \texttt{OBUF}).

\section{Conclusions}
The practice successfully founded the microelectronic design flow using the VHDL environment. It was empirically demonstrated that conceptual development undergoes deep compression when synthesized into silicon hardware. The AMD Vivado compiler optimized extensive gate networks into the physical space of a single LUT. 

Likewise, the performance analysis demonstrated that in dense lithographies, the main circuit latency ($>57\%$) resides in the electromagnetic propagation through the physical routing channels of the board, eclipsing the transistor switching itself of the logic cells. This exercise confirms the usefulness of FPGAs in RTL design, covering the workflow from abstract description to its mapping, implementation, and functional verification.
